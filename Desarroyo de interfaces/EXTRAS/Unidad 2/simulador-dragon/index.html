El Cuaderno del Jinete

Simulador para aprender a montar un dragón paso a paso

Sigue las instrucciones del cuaderno y controla el simulador con gestos de la mano delante de la cámara.

La cámara necesita abrir la página con un servidor local (Live Server o python -m http.server) en Chrome o Edge.
